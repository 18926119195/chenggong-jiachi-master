# 全量材料生成说明

## 背景

实验组一原本设计为"不筛选、全量材料"，但受限于 DeepSeek API 的上下文窗口（128K tokens），实际只能使用前 100 个 chunks。

为了测试全量 1446 chunks 的推理效果，生成了带机器符号的完整材料文件，用于上传到 DeepSeek 官网聊天进行人工测试。

## 文件说明

### `full-chunks-with-symbols-Z1-Q1.txt`
- **内容**: Z1-Q1 问题的全部 1446 个候选 chunks
- **格式**: 每个 chunk 前标记 `【【id】】`，方便 LLM 引用
- **大小**: 约 610 KB
- **用途**: 上传到 DeepSeek 官网聊天，测试全量材料推理

### `generate-full-chunks-with-symbols.py`
- **功能**: 从 `candidate-texts-for-llm-cot.json` 读取数据，生成带符号的全量材料文件
- **运行方式**:
  ```bash
  cd "C:\Users\Administrator\Desktop\2026-09-21-master\cot对比实验"
  python generate-full-chunks-with-symbols.py
  ```

## 使用流程

1. **生成文件** (已完成)
   ```powershell
   python generate-full-chunks-with-symbols.py
   ```

2. **上传到 DeepSeek 官网**
   - 访问 https://chat.deepseek.com
   - 拖拽 `full-chunks-with-symbols-Z1-Q1.txt` 到聊天窗口
   - 配上提示词，例如：
     ```
     请基于上传文件中的全部材料，回答：Pierre Janet 和 Freud 对无意识的观点有何不同？
     请给出完整推理路径，并标注引用的材料编号【【id】】。
     ```

3. **对比分析**
   - API 实验组一（100 chunks 限制版）
   - 官网聊天测试（1446 chunks 全量版）
   - 注意：官网测试不作为严格对比组（参数不完全可控），仅作参考

## 技术限制说明

### DeepSeek API 限制
- **上下文窗口**: 128K tokens
- **估算**: 1446 chunks ≈ 15-18 万 tokens（超出限制）
- **实际使用**: `COT_MAX_CHUNKS=100` 约 12-13K tokens（安全范围内）

### 官网与 API 的差异
- 官网可能使用 RAG、动态检索或分段推理（对用户透明）
- 参数设置可能不同（temperature、max_tokens 等）
- 不适合作为严格对照实验，但可作为定性参考

## 实验建议

保留当前 API 实验组一的 100-chunk 设计作为可复现的对比基线，官网全量测试作为补充验证。实验报告可注明：

> 实验组一受 API 上下文窗口限制取前 100 chunks（约占全量材料的 6.9%）；  
> 额外在官网聊天进行了全量 1446 chunks 验证（不作为严格对比组）。
