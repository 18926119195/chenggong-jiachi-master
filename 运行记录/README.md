## 🐛 常见问题

### 1. API Key 未生效
**症状**: 设置了新 key 但缓存命中率仍很高

**排查步骤**:
1. 检查 `.env` 文件中的 `LLM_API_KEY`
2. 确认代码中是否有硬编码的旧 key
3. 在 PowerShell 命令中显式设置 `$env:LLM_API_KEY='新key'`
4. 通过精打/推理阶段的缓存命中率验证（应为 0%）

### 2. 找不到问题
**症状**: 运行显示 "问题数: 0" 或找不到指定的 question ID

**排查步骤**:
1. 清空 `$env:QUESTIONS_PATH=''` 使用默认的 `test-questions.json`
2. 检查 `test-questions.json` 中是否包含该问题 ID
3. 确认 `$env:QUESTION_IDS='Z3-Q2'` 格式正确（大小写敏感）

### 3. dotenv 未加载
**症状**: `.env` 文件修改后不生效

**原因**: 主流程脚本都不使用 `dotenv` 库

**解决方案**: 
- 在每次运行前手动设置环境变量
- 或使用提供的 `run-z3q2-complete.ps1` 脚本（已内置环境变量设置）
