# 关闭思维链的配置说明

## 核心配置位置

文件：`src\core\llmClient.js`

## 关键代码片段（第54-65行）

```javascript
body: JSON.stringify({
  model: LLM_MODEL,
  messages: [{ role: 'user', content: prompt }],
  max_tokens: maxTokens,
  temperature: 0.0,
  stream: false,
  reasoning_effort: 'none'  // ← 这是关闭思维链的关键配置
})
```

## 说明

- **参数名称**：`reasoning_effort`
- **值**：`'none'`
- **作用**：禁用LLM的推理思维链（CoT），让模型直接输出答案，不生成中间推理过程

## 涉及此LLM客户端的所有脚本

1. `recall-nouns-llm.js` - 名词召回（粗筛+精打分）
2. `build-prompt-with-traceback.js` - 构建推理输入
3. `generate-multipath-prompt.js` - 生成多路径Prompt
4. `run-reasoning.js` - 执行推理

所有这些脚本都通过 `import { callLLM } from './src/core/llmClient.js'` 引用同一个LLM客户端，因此**统一关闭了思维链**。

## 验证方式

检查任何LLM调用生成的快照文件（`llm-snapshots/call-XXXX-request.json`），确认请求体中包含：
```json
{
  "reasoning_effort": "none"
}
```
